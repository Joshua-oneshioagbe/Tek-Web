Leenzners | Project-Based Learning Platform

Leenzners is a modern, responsive educational landing page designed for the next generation of digital creators. It features a clean split-hero layout, a dynamic course grid, and a mobile-first navigation system with a functional hamburger menu.

🚀 Features
Dynamic Course Loading: Courses are injected via JavaScript to allow for easy updates without touching the HTML structure.

Mobile-First Design: Fully responsive layout that adapts from large monitors to small mobile screens.

Interactive UI: Includes a custom-built hamburger menu for mobile navigation and smooth-scroll anchors.

Lead Capture: A functional enrollment form with instant validation feedback.

🛠️ Tech Stack
HTML5: Semantic structure.

CSS3: Custom properties (variables), CSS Grid, Flexbox, and Media Queries for responsiveness.

JavaScript (ES6): DOM manipulation for dynamic content and navigation logic.

Google Fonts: 'Inter' typeface for a high-end, technical aesthetic.

leenzners/
├── index.html    # The skeleton and SEO meta tags
├── style.css     # Design system and responsive breakpoints
├── script.js     # Course data and navigation logic
└── README.md     # Project documentation

💻 How to Run This Project
Clone or Download: Save the index.html, style.css, and script.js files into a single folder named leenzners.

Open: Locate index.html in your file explorer.

Launch: Right-click the file and select Open with... followed by your preferred web browser (Chrome, Firefox, or Safari).
